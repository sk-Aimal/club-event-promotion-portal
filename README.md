# club-event-promotion-portal
Dynamic university event promotion website built with PHP, MySQL, HTML, CSS, and JavaScript featuring registration, announcements, and admin controls.
# Club Event Promotion Website – Dynamic University Event Portal

A full stack event promotion and management website created to allow students to browse upcoming university events, register for participation, and receive event announcements through a dynamic web platform.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap
- XAMPP

## Core Features
- User registration and login
- Dynamic event cards with image

- Event registration system
- Admin event management panel
- Event announcements and featured banners
- Session-based authentication
- CRUD operations for event management

## Project Purpose
Developed as a mobile and web development coursework project focusing on dynamic websites, user experience, database connectivity, and responsive design.
